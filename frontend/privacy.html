Política de Privacidade

Esta Política de Privacidade descreve como o JHC Viral Engine ("nós", "nosso") coleta, usa e protege suas informações quando você utiliza nosso aplicativo de automação de conteúdo para redes sociais.

1. Informações que Coletamos

  • Credenciais de autenticação: tokens OAuth2 concedidos por você para acessar suas contas do YouTube, Instagram e TikTok. Esses tokens são armazenados localmente em seu dispositivo e nunca compartilhados com terceiros.
  • Dados de uso da API: metadados de vídeos (títulos, descrições, IDs) obtidos via APIs oficiais das plataformas para fins de agendamento e publicação automática.
  • Logs operacionais: registros de publicações realizadas, erros e status do sistema, armazenados localmente para diagnóstico e auditoria.

2. Como Usamos Suas Informações

  • Autenticar e autorizar acesso às suas contas de redes sociais via OAuth2.
  • Publicar conteúdo automaticamente nas plataformas autorizadas por você.
  • Monitorar o status de publicações e fornecer relatórios operacionais no dashboard.
  • Diagnosticar falhas técnicas e melhorar a estabilidade do sistema.

3. Armazenamento e Segurança

  • Todos os tokens OAuth e credenciais são armazenados exclusivamente em seu dispositivo local, em arquivos protegidos por permissões restritas (chmod 600).
  • Nenhum dado sensível é transmitido para servidores externos além das APIs oficiais das plataformas (Google, Meta, TikTok).
  • O backend opera localmente em seu MacBook ou em servidor dedicado sob sua administração.
  • Credenciais e tokens nunca são incluídos em commits Git, logs públicos ou respostas de API.

4. Compartilhamento de Dados

Não vendemos, alugamos ou compartilhamos suas informações pessoais com terceiros. Os únicos serviços externos que recebem dados são as APIs oficiais das plataformas de redes sociais que você autorizou explicitamente via OAuth2.

5. Seus Direitos

  • Revogar acesso: você pode revogar tokens OAuth a qualquer momento através do dashboard ou diretamente nas configurações de segurança de cada plataforma.
  • Excluir dados: todos os dados são armazenados localmente. Para excluir, remova os arquivos do diretório data/ do projeto.
  • Portabilidade: seus dados estão em formatos abertos (JSON) e podem ser exportados a qualquer momento.

6. Serviços de Terceiros

  • YouTube Data API v3 — Google LLC (Política de Privacidade do Google)
  • Instagram Graph API — Meta Platforms Inc. (Política de Privacidade da Meta)
  • TikTok Content Posting API — ByteDance Ltd. (Política de Privacidade do TikTok)
  • Netlify — hospedagem do frontend estático (Política de Privacidade do Netlify)

7. Alterações nesta Política

Podemos atualizar esta política periodicamente. A data da última atualização será sempre indicada abaixo. Recomendamos revisar esta página regularmente.
